Usage: -c chat [OPTIONS]

  查看沟通列表（支持按发起方、时间筛选，支持导出）

Options:
  --page INTEGER               页码
  --from [boss|me]             筛选发起方：boss=对方主动联系 / me=我主动打招呼
  --days INTEGER               只显示最近 N 天的记录
  --export [html|md|csv|json]  导出格式：html=HTML / md=Markdown / csv=CSV /
                               json=JSON
  -o, --output TEXT            输出文件路径（不指定则自动保存到配置的 export_dir）
  --help                       Show this message and exit.
