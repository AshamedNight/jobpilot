## 1. 怎么在 Windows 上跑起来

```powershell
cd D:\code\jobpilot          # 只要 jobpilot/ 在这一层
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt

python -m pytest -q
uvicorn app.main:app --host 127.0.0.1 --port 8010
```

浏览器开 <http://127.0.0.1:8010>（接口文档：<http://127.0.0.1:8010/docs>）。

Linux / Termux：

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python -m pytest -q
uvicorn app.main:app --host 127.0.0.1 --port 8010
```

**前置要求**：Python ≥ 3.11（本次在 3.12.3 上验过）。
`.env` **不需要** —— 没有 Key 会降级运行（`llm_configured: false`），不报错退出。

### 11.6 三条口径（写死，供审计）

**① 计费口径（`calls_today` / `billable_calls_today`）**

```
calls_today = 今日 llm_calls 中
              model NOT IN ('template', 'template:fallback', 'cache', 'batch') 的行数
```

即**真正花钱的模型调用数**。`off` 模式下每岗仍写一条 `model='template'` 的行（流水线要可审计），
所以 **`llm_calls` 有行 ≠ 花过钱**。

两个键**同值同源**：一次查询算出整数，在同一个 dict 字面量里赋两个键，没有第二次 `COUNT(*)`。
将来要改口径：**改实现、不改键名**。

**② 缓存命中率**

```
命中率 = cache 行数 / (cache + live + batch 行数)
```

`template` / `template:fallback` **不进分母**（模板不是模型产出），也**不可被命中**——
`CacheWriter` 的 SQL 里写死了 `model NOT IN ('template','template:fallback')`，
否则模板文案会伪装成模型结果，审计口径直接作废。

**③ 模板选择（确定性）**

1. 命中数 = `match_words` 里出现在 `job.title` 的词数；命中最多的一组胜出
2. 命中数为 0 → 只在"兜底组"（`match_words` 为空）里选
3. 组内顺序 = **yaml 声明顺序**（平手 tie-break，无 `sorted()`、无字典序、无 `random`）
4. `idx = int(sha256(job_id), 16) % len(group)` **只在组内**做变体轮转；`len(group)==1` 时即声明在前那条

同一个 `job_id` 两次生成结果**恒定**（测试 8 钉住，跨 `LlmGateway` 实例也成立）。

`llm_configured: true` 但 `LlmHttpClient.available() == False` → `live` / `hybrid` **永远**
回落 `template:fallback`，`last_fallback_reason` 恒为 `no_api_key`。只有系统环境变量那条路能通。

**根因**：`load_config()` 算出 `api_key` 后只落了布尔 `llm_configured`，**没把 key 值本身放进 `cfg`**；
而 `LlmHttpClient.__init__` 只读 `os.environ.get("LLM_API_KEY")`，Phase 1 又已删掉
"把 `.env` 导出到 `os.environ`"的函数，于是两条路都断了。

**改动（3 处代码 + 2 条测试）**：

| 文件 | 改动 |
|---|---|
| `app/config.py` | `llm_configured` 定稿后新增一行 `merged["llm"]["api_key"] = api_key if llm_configured else ""`。只放**可用** key（占位符 `your-` / `sk-xxx` / `changeme` 一律放空串）；只放 `merged["llm"]`，**不放顶层**（顶层会撞 `merge_config` 同名键校验，也容易被整段带进日志/接口） |
